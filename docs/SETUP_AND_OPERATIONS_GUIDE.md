# دليل التثبيت والتشغيل وإعداد البريد الإلكتروني – TAOUNATE PHOTO BOOTH

## 1. نظرة عامة على المشروع
- **تطبيق Android (Kotlin + Jetpack Compose + CameraX)**:
  - واجهة رئيسية بهوية الملتقى (الأزرق الملكي، الذهبي، الأبيض، وزخارف مغربية) مع دعم كامل للغة العربية (RTL) والهواتف والأجهزة اللوحية.
  - كاميرا احترافية (CameraX) تدعم الكاميرا الأمامية والخلفية، ومؤقت 3 ثوانٍ، ومعاينة حية للإطار الرسمي.
  - دمج فعلي للصورة مع إطار PNG شفاف عالي الدقة مع الحفاظ على أبعاد الأشخاص وضبط الاتجاه تلقائياً.
  - وضع التشغيل المستمر (Kiosk): إبقاء الشاشة مضاءة، مسح بيانات الجلسة السابقة تلقائياً، والعودة للرئيسية عند الخمول.
  - لوحة إعدادات محمية للمنظم (الرمز الافتراضي: `2026`).
- **الإطار الرسمي PNG (بخلفية شفافة حقيقية)**:
  - نسخة عمودية: `frames/official_frame_portrait.png` (ومدمجة في `app/src/main/assets/frames/frame_portrait.png`)
  - نسخة أفقية: `frames/official_frame_landscape.png` (ومدمجة في `app/src/main/assets/frames/frame_landscape.png`)
- **الخادم الآمن (Backend)**:
  - موجود في مجلد `backend/` وجاهز للنشر على **Firebase Cloud Functions v2** أو **Google Cloud Run** أو أي خادم **Node.js 20+ HTTPS**.

---

## 2. تعليمات إعداد ونشر خادم البريد الإلكتروني (Backend)

### الخيار أ: النشر عبر Firebase Cloud Functions
1. أنشئ حساباً مجانياً أو مفعّلاً في **Resend** (`https://resend.com`) أو **SendGrid** (`https://sendgrid.com`)، وتحقق من نطاق البريد المرسل (`EMAIL_FROM`).
2. داخل مجلد `backend/`:
   ```bash
   npm install
   cp .env.example .env
   ```
3. املأ المتغيرات داخل `backend/.env` (أو عبر Firebase Secrets):
   - `EMAIL_PROVIDER=resend` (أو `sendgrid`)
   - `EMAIL_FROM=Taounate Forum <booth@your-verified-domain.com>`
   - `RESEND_API_KEY=...` (أو `SENDGRID_API_KEY=...`)
   - `CLIENT_APP_TOKEN=...` (كلمة سر قوية تختارها لحماية الواجهة من الاستخدام غير المصرح به)
4. انشر الدالة عبر HTTPS:
   ```bash
   firebase deploy --only functions
   ```
   ستحصل على رابط مثل:
   `https://europe-west1-YOUR_PROJECT_ID.cloudfunctions.net/api`

### الخيار ب: النشر عبر Cloud Run أو Render أو خادم Node.js
```bash
cd backend
npm install
PORT=8080 npm start
```
ثم اربط الخادم بـ HTTPS وضع الرابط في إعدادات التطبيق.

## 3. ربط التطبيق بالخادم وتوليد ملف APK
1. افتح التطبيق على الجهاز اللوحي أو الهاتف.
2. اضغط ضغطاً مطولاً على **شعار الملتقى** في الشاشة الرئيسية (أو 5 نقرات متتالية)، وأدخل رمز المنظم الافتراضي: **`2026`** (يُنصح بتغييره فور الدخول).
3. في قسم **«إعدادات خادم البريد الإلكتروني (HTTPS)»**:
   - أدخل رابط الخادم في خانة `Backend HTTPS Base URL` (مثلاً `https://.../api`).
   - أدخل `CLIENT_APP_TOKEN` في خانة `Client App Token`.
   - أدخل بريدك واضغط **«اختبار البريد/الخادم»** للتأكد من وصول الرسالة فعلياً.
4. لبناء ملف APK قابل للتثبيت محلياً:
   ```bash
   gradle :app:assembleRelease   # أو assembleDebug للتثبيت المباشر
   ```

---

## 4. تعليمات تغيير الإطار والشعارات (دون إعادة بناء التطبيق)
1. افتح **لوحة إعدادات المنظم** (ضغط مطول على الشعار -> رمز `2026`).
2. اضغط **«تغيير الشعار»** لاختيار شعار جديد من الجهاز.
3. لتغيير إطار التصوير:
   - جهّز ملف **PNG بخلفية شفافة حقيقية (RGBA)** في المنتصف لظهور الأشخاص.
   - اضغط **«رفع إطار عمودي PNG»** أو **«رفع إطار أفقي PNG»**.
   - يقوم التطبيق تلقائياً باكتشاف المنطقة الشفافة في الإطار ودمج الصور داخلها بدقة عالية، ويمكنك دائماً استعادة الإطار الافتراضي بضغطة زر.
